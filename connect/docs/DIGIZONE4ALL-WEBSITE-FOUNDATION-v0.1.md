# digizone4all.org.za — Proposed Website Foundation v0.1

**Date:** 2026-10-09. **Status:** Founder-side exploratory website preparation. Neither domain control nor DNS or production publication is verified/authorised.

## Role

DigiZone4All is the proposed public-facing digital inclusion and capability vehicle: **Visible. Connected. Capable.** / **People First. Technology Second.** The site could expose organisation discovery, practical tools and pathways to participation. It should not imply DigiZone owns IGV's underlying technology or that all ideas are ready for public service.

## Initial navigation and content

| Page | Visitor objective | Minimum useful content |
|---|---|---|
| Home | Understand why DigiZone exists | Explanation, three pillars, clear paths |
| Connect | Find an organisation | Searchable directory, profile links, accurate disclosure |
| Tools | Try a useful digital capability | Demo/proven labels for feedback and CV builder |
| How it works | Understand capture and publication | Steps, costs if any, permissions and limitations |
| About / Get involved | Learn who is involved, how to enquire | Accurate affiliations, approved contact and partner interest path |

## Proposed visitor journeys

1. **Visitor** → Connect directory → category/location search → public profile → approved contact link (future, NOT part of v0.2 demo).
2. **Small organisation** → Explanation → submit information/consent (future, NOT simulated JSON export) → review → approved publication → maintain/update.
3. **Learner** → Tools → CV builder or lessons → useful artifact → optional guidance.
4. **Partner** → About → evidence/cases with consent → partnership enquiry.

## Minimum data/publication requirements for real use

Confirmed brand and domain access; organisation data and consent; support/maintenance owner; correction/removal path; hosting privacy/security/POPIA review; truthful affiliate/partner attribution; official contact channel; funding and publication approvals. A fictional directory demo is not a public beneficiary directory.

## Rollout

1. Static demo on an isolated Vercel preview, fictional only; verify URLs.
2. Human review of actual site navigation, branding and commitments.
3. Only then plan production intake/consent and real organisation profiles; connect `.org.za` DNS separately after explicit authorization.

**Do not** change DNS, publish real client information or call this an IGV accepted product based on the demo.
